      Each day's priorities arrive as a push notification from KSUMobile, the app Kent students already have. Students see what needs attention without opening anything. Tapping it opens the full ACE panel.

      How ACE handles your data

      ACE reads from five systems Kent State already runs. It never changes a record, never submits work and never registers you for a class. Every item links back to the system it came from.
